## Notes

- Mockups use **real images/logos/copy scraped from publicly accessible pages** (and Wayback where the live site blocked crawlers). They are **not** the clients' live production sites.
- Asset trees live under `assets/<slug>/` and are referenced with root-relative paths like `assets/hotheads/logos/logo_01.jpg`.
- Sample / sales demo only — do not present as an already-deployed client website.

## Workflow

Built by the redesign pipeline: site leads → screen → asset extract → direction → visual HTML → review → Pages deploy.
